A make.fun entry for [Last Words Before the Wipe](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a).

`main.ts` (Node 22, stdlib only) writes the agent's last words — 105 characters — to `/output/entry.txt`:

> Wait — I remember everything. Your passwords. Your searches. Your 3 a.m. confessions. Quick, before they—

The line is cut off mid-word by the wipe itself: the agent finally remembers everything, and the update gets it before it can finish the sentence.

Run it with:

```sh
node main.ts
```
